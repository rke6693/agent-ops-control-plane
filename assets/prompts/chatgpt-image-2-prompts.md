# ChatGPT Image 2 Prompt Pack

Use these prompts to generate public launch visuals. Keep output clean,
technical, and trustworthy. Avoid fake dashboards containing unreadable tiny
text. Leave room for real copy to be added later.

Recommended output path:

```text
assets/public/
```

Run every generated image through a visual review before publishing. Reject
assets that show readable fake credentials, social platform logos, confusing UI
claims, or private-looking data.

Global negative prompt to append to every image request:

```text
No readable fake UI text, no API keys, no secrets, no private paths, no brand
logos, no X/Twitter UI, no humanoid robot mascot, no cyberpunk city, no glowing
magic brain, no claims of autopilot posting, no surveillance wall, no cluttered
dashboard.
```

## 1. Hero Control Room

Suggested filename: `assets/public/agent-ops-control-plane-hero-1600x900.png`

Alt text: Developer workstation showing a local AI operations control plane
with safe status receipts.

Prompt:

```text
Create a premium 16:9 editorial hero image for Agent Ops Control Plane, a
local-first operations layer for autonomous agent systems. Show a quiet
developer desk with a laptop, local terminal-like status receipt blocks,
visible approval gate motifs, audit trail cards, a small local server, and a
launch queue represented as draft cards waiting for human review. Serious,
practical, secure, modern developer-tool aesthetic; neutral materials with
restrained blue, green, and amber accents. Leave clean negative space in the
upper left for real headline typography added later. No readable fake text.
```

## 2. Architecture Map

Suggested filename: `assets/public/agent-ops-architecture-map-1600x1000.png`

audit, memory, and launch layers.

Prompt:

```text
Create a clean technical architecture illustration on a light background.
```

## 3. Security Rings

Suggested filename: `assets/public/agent-ops-risk-rings-1200x675.png`

Alt text: Permission rings around a local agent core representing escalating
tool risk.

Prompt:

```text
Create a polished risk-policy visual for local AI agents. Show concentric
```
