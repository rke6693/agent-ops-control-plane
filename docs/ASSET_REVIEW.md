# Launch Asset Review

This review records the public launch asset pass for Agent Ops Control Plane.
The assets support the GitHub repo, launch posts, and technical docs without
implying live social automation.

## Brand Position

Primary line:

```text
Agents need operations, not vibes.
```

Supporting message:

```text
Redacted receipts. Approval gates. Audit trails.
```

The brand posture is calm, technical, trustworthy, local-first, and aimed at
serious agent builders. Use language around operations, receipts, redaction,
risk classes, manual approval, dry runs, and audit trails. Avoid language that
implies hands-free posting, growth hacking, bot activity, guaranteed security,
or full autonomy without operator gates.

Visual review notes:

- No readable credentials, API keys, tokens, private paths, or private data were
  observed.
- The final launch-queue asset is icon-only and avoids autoposting claims.
- The operator receipt uses abstract status blocks rather than real terminal
  output.
- The OG/social image leaves negative space for real launch copy.
- One earlier launch-queue generation was rejected during review because it
  included readable generated copy and inaccurate security claims. It was not
  included in the committed asset set.

## Canva Candidate Lane

Canva was used to generate editable launch-card candidates through the Canva
connector. Candidate URLs and IDs are intentionally not committed because they
were not independently visual-QA'd as local bitmap exports.

Before any Canva candidate is converted, exported, linked publicly, or posted,
open it in Canva and reject it if it contains fake credentials, private-looking
logs, social platform logos, unreviewed claims, autoposting language, bot
imagery, or unreadable clutter.

## Design Review

Graphic design review result: `PASS`

Evidence:

- Asset set is consistent with a mature developer-tool aesthetic.
- Images favor systems, gates, receipts, and risk layers over mascot or hype
  visuals.
- The final public asset set avoids visible social-platform UI and readable
  fake secrets.
- The rejected launch-queue image was caught before commit and replaced.

Required operating constraint:

- Keep generated launch visuals as draft assets until a human operator approves
  the exact post copy and channel.

## Final Proposal

Use the Image 2 public asset set for the initial GitHub and launch materials.
Keep Canva as an editable design lane for optional manual polishing, but do not
publish or post any Canva design until a specific candidate is selected,
visually reviewed, exported, scanned where practical, and approved.
