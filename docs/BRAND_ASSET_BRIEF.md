# Brand And Asset Brief

## Brand Position

Agent Ops Control Plane is practical infrastructure for serious agent builders.
The brand should feel calm, technical, trustworthy, and local-first.

## Visual Principles

- Mature developer-tool aesthetic.
- Clear systems diagrams over hype visuals.
- Dark neutral and clean white variants.
- Restrained blue/green security accents.
- No fake API keys, tokens, private logs, or readable credentials.
- No social platform logos in generated images.
